# VERA観測テンプレートの作成

`vex_templates.py` は、完全なVEX例からツール用のJSONテンプレートを作ります。
ヘッダー・MODE・PROCEDURES・FREQ・IF・BBC・STATION・DAS・SITE・ANTENNAを組として扱います。
例示用の天体、スキャン、観測者情報は取り込みません。

## 名前を指定して作成

リポジトリ直下で実行します。既存のconda環境を利用できます。

```sh
conda activate schedule
python vex_templates.py ../vex_template_2025Sec30/VERAexample_AC_C_VERA4S_2G_32MHz16IF_NEW.vex --name "C_Cont_1B_2G"
```

`--name` は表示名の明示指定です。省略すると `template/display_names.json` の対応表を使います。
対応表にない場合は自動命名せず、名前の指定を求めてそのファイルをスキップします。
VEX内部のMODE識別子は変更しません。既存のJSONファイルは上書きしません。
別名の出力先が必要なら `--output 別ディレクトリ` を指定してください。

ディレクトリの一括変換:

```sh
python vex_templates.py ../vex_template_2025Sec30
```

既定の出力先は `template/observing/` です。次のアプリ起動時に読み込みます。
失敗したファイルは理由を表示し、正常なファイルの変換は続けます。失敗があれば終了コードは1です。
周波数設定だけのテキストは、他の装置設定が不足するため入力に使えません。

## 画面から利用

VERAの **Mode** タブの **Select from templates** に、新版の19件を表示します。旧形式のテンプレートは使用しません。
スキャンを追加する前に選択してください。観測情報と天体一覧は保持します。
スキャン追加後の適用は、MODE参照やビーム構成の不一致を防ぐため拒否します。

テンプレートは管理者が上記コマンドで事前に作成し、画面では選択だけを行います。
表示名は作成時の `--name` で指定してください。
既存VEXの読み込み・編集は従来のImport機能を使用します。
生成JSONをリポジトリに含め、Dockerも同じ `template/observing/` を読み込みます。

## 配布例の確認結果

2026-09-22に修正された2件を含む19件が、構造の変換・参照確認を通過しました。
`VERAsample.vex` は具体的な観測テンプレートではないため、一括変換から除外します。
これは観測装置での動作保証ではありません。
元資料のREADMEにもNEW付きの一部設定は完全なチェックが済んでいない旨が記載されています。

新版への統一に伴い、生成JSONを `template/observing/` にまとめています。
旧pickleテンプレートの一覧・読み込み・差し替え処理は廃止しました。
元の配布VEXや第三者製変換プログラムは、このディレクトリには含めません。
